# Stock Market Performance Analysis | Prompt Workflows

> A companion repository documenting AI-assisted workflows used during the development of the Stock Market Performance Analysis project.

## Purpose

This repository separates the **prompt engineering and AI-assisted development layer** from the main analytics project. It is intended to show how structured prompts can support data analysis, dashboard planning, DAX development, documentation, and presentation work.

## Workflow

```text
Business Requirement
        ↓
Prompt Design
        ↓
AI-Assisted Analysis / Development
        ↓
Validation with Data
        ↓
Power BI Dashboard
        ↓
Business Storytelling
```

## Prompt Categories

- Data cleaning and preparation
- Exploratory data analysis
- Power BI dashboard planning
- DAX measure development
- KPI and visual design
- Insight generation
- Executive summary writing
- Documentation improvement

## Related Project

The outputs and workflows documented here support the main **Stock Market Performance Analysis** portfolio project.
